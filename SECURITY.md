# Security Policy · 安全策略

## Reporting a Vulnerability / 报告安全漏洞

If you discover a security vulnerability in **Lekis Music (月兔音乐)** — such as credential leakage, path traversal in VFS/scanner, unsafe plugin sandbox behavior, or Connect pairing/authentication flaws — please **do not** open a public issue.

Instead, report it privately via [GitHub Security Advisories](https://github.com/aoxzh/lekis-music/security/advisories/new).

Please include:
- A clear description of the vulnerability and affected component (`core/crates/...` or `app/...`).
- Minimal steps to reproduce or a proof of concept.
- The app version and platform tested.

We will acknowledge receipt as soon as possible and coordinate a fix before public disclosure.
