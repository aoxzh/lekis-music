## 新增

- **下载搜索**：下载数量较多时，筛选标签上方出现搜索框，可按歌名/艺人即时过滤；分类数量和空结果提示随搜索更新。
- 包含 0.2.62 的下载分组缓存、0.2.61 的 O(1) 下载状态索引和 0.2.60 的下载行操作。

## English

Lekis Music 0.2.63 preview release, adding search to the downloads list. Please [open an issue](https://github.com/aoxzh/lekis-music/issues) for problems.

**New**

- **Download search**: when a library has many downloads, a search field appears above the filter chips and filters by title or artist as you type; group counts and the empty state follow the query.
- Includes the 0.2.62 cached download groups, 0.2.61 O(1) download lookup and 0.2.60 download-row actions.

**Downloads:** Android arm64 APK; Windows x64 installer or portable ZIP; macOS arm64 DMG or ZIP; Linux x64 AppImage or tar.gz. Checksums are in `SHA256SUMS.txt`.
