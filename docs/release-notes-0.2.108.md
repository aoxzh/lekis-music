月兔音乐（Lekis Music）0.2.108 预览版，歌单支持一键随机播放。有问题欢迎[提 issue](https://github.com/aoxzh/lekis-music/issues)。

## 新增

- **歌单随机播放**：歌单详情页在「播放」旁新增随机播放按钮，直接打乱整个歌单开播。
- 包含 0.2.107 的歌单合并、0.2.106 的队列移除重复曲目和 0.2.105 的分页预取。

## English

Lekis Music 0.2.108 preview release, adding one-tap shuffle play for playlists. Please [open an issue](https://github.com/aoxzh/lekis-music/issues) for problems.

**New**

- **Shuffle a playlist**: the playlist detail header now has a shuffle button next to Play, starting the whole playlist in random order.
- Includes the 0.2.107 playlist merge, 0.2.106 queue duplicate removal and 0.2.105 page prefetch.

**Downloads:** Android arm64 APK; Windows x64 installer or portable ZIP; macOS arm64 DMG or ZIP; Linux x64 AppImage or tar.gz. Checksums are in `SHA256SUMS.txt`.
