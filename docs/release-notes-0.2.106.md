月兔音乐（Lekis Music）0.2.106 预览版，播放队列可以移除重复曲目。有问题欢迎[提 issue](https://github.com/aoxzh/lekis-music/issues)。

## 新增

- **队列移除重复曲目**：播放队列菜单可清理重复条目，每个曲目保留第一次出现；正在播放的曲目不会被移除，带确认和进度。
- 包含 0.2.105 的分页预取、0.2.104 的打乱未播放曲目和 0.2.103 的电台本地搜索。

## English

Lekis Music 0.2.106 preview release, adding duplicate removal for the playback queue. Please [open an issue](https://github.com/aoxzh/lekis-music/issues) for problems.

**New**

- **Remove duplicate queue tracks**: the queue menu removes repeated entries while keeping the first occurrence; the currently playing row is never removed, with confirmation and progress.
- Includes the 0.2.105 page prefetch, 0.2.104 shuffle-upcoming action and 0.2.103 local radio search.

**Downloads:** Android arm64 APK; Windows x64 installer or portable ZIP; macOS arm64 DMG or ZIP; Linux x64 AppImage or tar.gz. Checksums are in `SHA256SUMS.txt`.
