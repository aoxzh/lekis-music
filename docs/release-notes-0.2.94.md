月兔音乐（Lekis Music）0.2.94 预览版，播放历史可以搜索和复制。有问题欢迎[提 issue](https://github.com/aoxzh/lekis-music/issues)。

## 新增

- **播放历史搜索与复制**：播放历史页在记录较多时显示搜索框，可按歌名/艺人过滤；右上角可复制当前列表为文本。
- 包含 0.2.93 的队列移到顶部/底部、0.2.92 的队列内查找和 0.2.91 的详情缓存。

## English

Lekis Music 0.2.94 preview release, adding search and copy to playback history. Please [open an issue](https://github.com/aoxzh/lekis-music/issues) for problems.

**New**

- **Playback history search and copy**: longer histories show a search field for title/artist, and the app bar can copy the current list as numbered text.
- Includes the 0.2.93 queue move-to-top/bottom, 0.2.92 queue find and 0.2.91 detail cache.

**Downloads:** Android arm64 APK; Windows x64 installer or portable ZIP; macOS arm64 DMG or ZIP; Linux x64 AppImage or tar.gz. Checksums are in `SHA256SUMS.txt`.
