月兔音乐（Lekis Music）0.2.49 预览版，播放队列里的歌曲可以直接添加到歌单。有问题欢迎[提 issue](https://github.com/aoxzh/lekis-music/issues)。

## 新增

- **队列曲目添加到歌单**：播放队列行的长按/更多菜单新增「添加到歌单」，可直接选择现有歌单或新建歌单，并提示是否已在歌单中。
- 包含 0.2.48 的艺人页展开全部歌曲、0.2.47 的下载艺人全部歌曲和 0.2.46 的下载列表刷新优化。

## English

Lekis Music 0.2.49 preview release, adding queue-to-playlist. Please [open an issue](https://github.com/aoxzh/lekis-music/issues) for problems.

**New**

- **Add queue tracks to a playlist**: the queue row menu now offers "Add to Playlist", with the existing playlist picker or a new playlist, and a notice when the track is already there.
- Includes the 0.2.48 expandable artist songs, 0.2.47 download-all-for-artist and 0.2.46 downloads refresh optimization.

**Downloads:** Android arm64 APK; Windows x64 installer or portable ZIP; macOS arm64 DMG or ZIP; Linux x64 AppImage or tar.gz. Checksums are in `SHA256SUMS.txt`.
