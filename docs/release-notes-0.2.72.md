- **复制播放队列**：队列更多菜单新增「复制队列」，按「序号. 歌名 — 艺人」复制到剪贴板；超过 500 首时只复制前 500 首并提示。
- 包含 0.2.71 的正在播放查看专辑/艺人、0.2.70 的播放历史一键播放和 0.2.69 的首页歌架播放。

## English

Lekis Music 0.2.72 preview release, adding Copy Queue as text. Please [open an issue](https://github.com/aoxzh/lekis-music/issues) for problems.

**New**

- **Copy the playback queue**: the queue More menu copies a numbered "Title — Artist" list to the clipboard; queues over 500 tracks copy the first 500 with a notice.
- Includes the 0.2.71 Now Playing album/artist links, 0.2.70 playback-history actions and 0.2.69 home-shelf actions.

**Downloads:** Android arm64 APK; Windows x64 installer or portable ZIP; macOS arm64 DMG or ZIP; Linux x64 AppImage or tar.gz. Checksums are in `SHA256SUMS.txt`.
