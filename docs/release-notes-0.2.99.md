月兔音乐（Lekis Music）0.2.99 预览版，搜索结果可以逐步加载更多。有问题欢迎[提 issue](https://github.com/aoxzh/lekis-music/issues)。

## 新增

- **搜索结果加载更多**：搜索结果达到当前上限时显示「显示更多结果」，可逐步加载到 100 条；修改查询会重置。
- 包含 0.2.98 的搜索结果缓存、0.2.97 的下载筛选后播放和 0.2.96 的播放历史缓存。

## English

Lekis Music 0.2.99 preview release, adding "show more" to search results. Please [open an issue](https://github.com/aoxzh/lekis-music/issues) for problems.

**New**

- **Load more search results**: when a section reaches the current limit, a Show More button increases it in steps up to 100; changing the query resets the limit.
- Includes the 0.2.98 search-result cache, 0.2.97 play-filtered-downloads and 0.2.96 playback-history cache.

**Downloads:** Android arm64 APK; Windows x64 installer or portable ZIP; macOS arm64 DMG or ZIP; Linux x64 AppImage or tar.gz. Checksums are in `SHA256SUMS.txt`.
