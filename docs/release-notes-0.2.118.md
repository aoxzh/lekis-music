## 新增

- **搜索结果批量操作**：歌曲结果区的更多菜单可把当前结果保存成新歌单，或把全部未下载曲目加入下载队列。
- 包含 0.2.117 的歌单多选批量移除、0.2.116 的长列表播放完整队列和 0.2.115 的启动并行初始化。

## English

Lekis Music 0.2.118 preview release, with bulk actions for search results. Please [open an issue](https://github.com/aoxzh/lekis-music/issues) for problems.

**New**

- **Search result batch actions**: the songs section menu can save the current results as a new playlist or queue every not-yet-downloaded track for download.
- Includes the 0.2.117 playlist multi-select batch removal, 0.2.116 full-queue playback from long lists and 0.2.115 parallel startup initialization.

**Downloads:** Android arm64 APK; Windows x64 installer or portable ZIP; macOS arm64 DMG or ZIP; Linux x64 AppImage or tar.gz. Checksums are in `SHA256SUMS.txt`.
