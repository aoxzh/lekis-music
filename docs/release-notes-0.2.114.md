月兔音乐（Lekis Music）0.2.114 预览版，资料库多选可以直接加入歌单。有问题欢迎[提 issue](https://github.com/aoxzh/lekis-music/issues)。

## 新增

- **资料库多选加入歌单**：多选曲目后可直接选择目标歌单批量添加，带进度和失败数量；智能歌单不可选。
- 包含 0.2.113 的喜欢页保存为歌单、0.2.112 的播放历史保存为歌单和 0.2.111 的喜欢页整组下载。

## English

Lekis Music 0.2.114 preview release, adding batch add-to-playlist from library selections. Please [open an issue](https://github.com/aoxzh/lekis-music/issues) for problems.

**New**

- **Add selected library tracks to a playlist**: after multi-selecting songs, pick a target playlist to add them in bulk, with progress and a failure count; smart playlists cannot be selected.
- Includes the 0.2.113 Liked Songs save-as-playlist, 0.2.112 history save-as-playlist and 0.2.111 Liked Songs batch download.

**Downloads:** Android arm64 APK; Windows x64 installer or portable ZIP; macOS arm64 DMG or ZIP; Linux x64 AppImage or tar.gz. Checksums are in `SHA256SUMS.txt`.
