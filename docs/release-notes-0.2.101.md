## 新增

- **歌单清理缺失曲目**：歌单更多菜单可移除无法解析的条目，保留其他曲目；带确认、进度和失败数量。
- 包含 0.2.100 的移除重复曲目、0.2.99 的搜索结果加载更多和 0.2.98 的搜索缓存。

## English

Lekis Music 0.2.101 preview release, adding missing-track cleanup for playlists. Please [open an issue](https://github.com/aoxzh/lekis-music/issues) for problems.

**New**

- **Clean missing playlist tracks**: a playlist menu action removes entries that no longer resolve while keeping the rest, with confirmation, progress, and a failure count.
- Includes the 0.2.100 duplicate removal, 0.2.99 search load-more and 0.2.98 search cache.

**Downloads:** Android arm64 APK; Windows x64 installer or portable ZIP; macOS arm64 DMG or ZIP; Linux x64 AppImage or tar.gz. Checksums are in `SHA256SUMS.txt`.
