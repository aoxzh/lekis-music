- 包含 0.2.39 的清理已完成下载、0.2.38 的歌词偏移浮条和 0.2.37 的 WAL 检查点优化。

## English

Lekis Music 0.2.40 preview release, adding a copy-track-info action to Now Playing. Please [open an issue](https://github.com/aoxzh/lekis-music/issues) for problems.

**New**

- **Copy track info**: Now Playing's More menu now copies "Title — Artist — Album" to the clipboard for sharing or looking things up.
- Includes the 0.2.39 clear completed downloads, 0.2.38 quick lyric-offset bar and 0.2.37 WAL checkpoint tuning.

**Downloads:** Android arm64 APK; Windows x64 installer or portable ZIP; macOS arm64 DMG or ZIP; Linux x64 AppImage or tar.gz. Checksums are in `SHA256SUMS.txt`.
