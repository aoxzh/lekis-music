月兔音乐（Lekis Music）0.2.28 预览版，外观设置新增五种强调色预设。有问题欢迎[提 issue](https://github.com/aoxzh/lekis-music/issues)。

## 新增

- **强调色预设**：设置 → 外观新增月升紫（默认）/ 深海蓝 / 森林绿 / 玫瑰红 / 琥珀金五种强调色，按钮、进度条、选中态和正在播放的强调元素会一起切换；首帧前恢复上次选择，写入 `ui.accent`。
- 包含 0.2.27 的歌词面板下一首预取、0.2.26 的桌面封面解码缓存和 0.2.25 的快速均衡器。

## English

Lekis Music 0.2.28 preview release, adding five accent presets to Appearance settings. Please [open an issue](https://github.com/aoxzh/lekis-music/issues) for problems.

**New**

- **Accent presets**: Appearance now offers Moonrise (default), Ocean, Forest, Rose and Amber. Buttons, progress bars, selected states and Now Playing accents switch together; the choice is restored before the first frame and stored in `ui.accent`.
- Includes the 0.2.27 lyrics-pane next-track prefetch, 0.2.26 desktop artwork cache and 0.2.25 quick equalizer.

**Downloads:** Android arm64 APK; Windows x64 installer or portable ZIP; macOS arm64 DMG or ZIP; Linux x64 AppImage or tar.gz. Checksums are in `SHA256SUMS.txt`.
