月兔音乐（Lekis Music）0.2.104 预览版，播放队列可以打乱未播放曲目。有问题欢迎[提 issue](https://github.com/aoxzh/lekis-music/issues)或参与讨论。

## 新增

- **打乱未播放曲目**：播放队列菜单可随机重排当前曲目之后的条目，当前播放不中断；带确认提示和失败计数。
- 包含 0.2.103 的电台本地搜索、0.2.102 的清除未播放曲目和 0.2.101 的歌单清理缺失曲目。

## English

Lekis Music 0.2.104 preview release, adding shuffle for upcoming queue tracks. Please [open an issue](https://github.com/aoxzh/lekis-music/issues) for problems.

**New**

- **Shuffle upcoming tracks**: the queue menu randomly reorders everything after the current track without interrupting playback, behind a confirmation dialog with a failure count.
- Includes the 0.2.103 local radio search, 0.2.102 clear-upcoming action and 0.2.101 missing-playlist-track cleanup.

**Downloads:** Android arm64 APK; Windows x64 installer or portable ZIP; macOS arm64 DMG or ZIP; Linux x64 AppImage or tar.gz. Checksums are in `SHA256SUMS.txt`.
