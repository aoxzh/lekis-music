月兔音乐（Lekis Music）0.2.77 预览版，下载列表可以按标题/时间/大小排序。有问题欢迎[提 issue](https://github.com/aoxzh/lekis-music/issues)。

## 新增

- **下载排序**：下载页新增排序菜单，可按默认、标题、最新添加或文件最大排序；与搜索/筛选同时生效。
- 包含 0.2.76 的在文件夹中显示、0.2.75 的复制歌单和 0.2.74 的图片缓存管理。

## English

Lekis Music 0.2.77 preview release, adding sorting to the downloads list. Please [open an issue](https://github.com/aoxzh/lekis-music/issues) for problems.

**New**

- **Downloads sorting**: the Downloads page can sort by default, title, newest, or largest file; sorting combines with the search and status filters.
- Includes the 0.2.76 show-in-folder, 0.2.75 copy playlist and 0.2.74 image-cache management.

**Downloads:** Android arm64 APK; Windows x64 installer or portable ZIP; macOS arm64 DMG or ZIP; Linux x64 AppImage or tar.gz. Checksums are in `SHA256SUMS.txt`.
