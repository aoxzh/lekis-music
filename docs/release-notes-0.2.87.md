月兔音乐（Lekis Music）0.2.87 预览版，最近搜索可以逐条删除。有问题欢迎[提 issue](https://github.com/aoxzh/lekis-music/issues)。

## 新增

- **最近搜索逐条删除**：搜索页最近搜索标签改为可删除，点 × 只移除该关键词，仍可一键清空。
- 包含 0.2.86 的歌单时长排序、0.2.85 的键盘快捷键帮助和 0.2.84 的专辑页更多来自。

## English

Lekis Music 0.2.87 preview release, adding per-item removal to recent searches. Please [open an issue](https://github.com/aoxzh/lekis-music/issues) for problems.

**New**

- **Remove recent searches individually**: the recent-search chips now have a × that removes only that query; Clear All still works.
- Includes the 0.2.86 playlist duration sort, 0.2.85 keyboard-shortcuts help and 0.2.84 More by artist shelf.

**Downloads:** Android arm64 APK; Windows x64 installer or portable ZIP; macOS arm64 DMG or ZIP; Linux x64 AppImage or tar.gz. Checksums are in `SHA256SUMS.txt`.
