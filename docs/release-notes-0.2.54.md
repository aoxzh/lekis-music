## 新增

- **Windows 托盘显示当前歌曲**：悬停托盘图标会显示「歌名 — 艺人 · Lekis Music」，切歌时同步更新，长标题自动截断；没有播放时仍显示应用名。
- 包含 0.2.53 的复制歌词、0.2.52 的流派页下载全部歌曲和 0.2.51 的下载列表筛选。

## English

Lekis Music 0.2.54 preview release, showing the current track in the Windows tray tooltip. Please [open an issue](https://github.com/aoxzh/lekis-music/issues) for problems.

**New**

- **Windows tray now-playing tooltip**: hovering the tray icon shows "Title — Artist · Lekis Music", updates when the track changes, truncates long titles, and falls back to the app name when nothing is playing.
- Includes the 0.2.53 copy lyrics, 0.2.52 genre download-all and 0.2.51 downloads filters.

**Downloads:** Android arm64 APK; Windows x64 installer or portable ZIP; macOS arm64 DMG or ZIP; Linux x64 AppImage or tar.gz. Checksums are in `SHA256SUMS.txt`.
