月兔音乐（Lekis Music）0.2.24 预览版，音源页可以一键扫描全部已启用音源。有问题欢迎[提 issue](https://github.com/aoxzh/lekis-music/issues)。

## 新增

- **一键扫描全部音源**：音源页标题栏新增「扫描全部音源」按钮（桌面也可按 Shift+F5），依次启动所有已启用音源的扫描；没有启用音源时会提示，启动失败的音源会在完成提示里计数。
- 包含 0.2.23 的音质标签打开来源 / 复制路径、0.2.22 的来源列表和 0.2.21 的下一首封面预取。

## English

Lekis Music 0.2.24 preview release, adding one-click scanning for all enabled sources. Please [open an issue](https://github.com/aoxzh/lekis-music/issues) for problems.

**New**

- **Scan all sources**: the Sources header now has a "Scan All Sources" button (also Shift+F5 on desktop) that starts a scan for every enabled source. It tells you when none are enabled and counts sources that failed to start.
- Includes the 0.2.23 quality badge → source list / copy path, 0.2.22 source list and 0.2.21 next-cover prefetch.

**Downloads:** Android arm64 APK; Windows x64 installer or portable ZIP; macOS arm64 DMG or ZIP; Linux x64 AppImage or tar.gz. Checksums are in `SHA256SUMS.txt`.
