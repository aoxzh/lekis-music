- 包含 0.2.21 的下一首封面预取、0.2.20 的队列长按直达专辑 / 艺人和 0.2.19 的队列长按收藏 / 排序 / 移除。

## English

Lekis Music 0.2.22 preview release, adding a source list for the current track. Please [open an issue](https://github.com/aoxzh/lekis-music/issues) for problems.

**New**

- **View all track sources**: Now Playing's "More" menu now opens a source list showing every local / NAS / media-server copy, with format, size, quality score, reachability, the preferred copy and any unreachable ones.
- Includes the 0.2.21 next-cover prefetch, 0.2.20 queue album/artist links and 0.2.19 queue long-press favorite/reorder/remove.

**Downloads:** Android arm64 APK; Windows x64 installer or portable ZIP; macOS arm64 DMG or ZIP; Linux x64 AppImage or tar.gz. Checksums are in `SHA256SUMS.txt`.
