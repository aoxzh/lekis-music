月兔音乐（Lekis Music）0.2.112 预览版，播放历史可以保存成歌单。有问题欢迎[提 issue](https://github.com/aoxzh/lekis-music/issues)。

## 新增

- **播放历史保存为歌单**：播放历史页可把当前列表（含搜索过滤结果）保存成新歌单，带命名、进度和失败数量。
- 包含 0.2.111 的喜欢页整组下载、0.2.110 的喜欢页随机播放和 0.2.109 的电台本地排序。

## English

Lekis Music 0.2.112 preview release, letting you save playback history as a playlist. Please [open an issue](https://github.com/aoxzh/lekis-music/issues) for problems.

**New**

- **Save playback history as a playlist**: the history page can turn the current list (including search-filtered results) into a new playlist, with naming, progress and a failure count.
- Includes the 0.2.111 Liked Songs batch download, 0.2.110 Liked Songs shuffle and 0.2.109 radio local sort.

**Downloads:** Android arm64 APK; Windows x64 installer or portable ZIP; macOS arm64 DMG or ZIP; Linux x64 AppImage or tar.gz. Checksums are in `SHA256SUMS.txt`.
