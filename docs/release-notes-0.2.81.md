## English

Lekis Music 0.2.81 preview release, adding play-all/shuffle to Top Tracks in stats. Please [open an issue](https://github.com/aoxzh/lekis-music/issues) for problems.

**New**

- **Play or shuffle Top Tracks**: the Top Tracks heading in Listening Stats now has both actions.
- Includes the 0.2.80 downloads cache, 0.2.79 stats navigation and 0.2.78 playlist entry moves.

**Downloads:** Android arm64 APK; Windows x64 installer or portable ZIP; macOS arm64 DMG or ZIP; Linux x64 AppImage or tar.gz. Checksums are in `SHA256SUMS.txt`.
