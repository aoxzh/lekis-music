## English

Lekis Music 0.2.89 preview release, showing where the current lyrics came from. Please [open an issue](https://github.com/aoxzh/lekis-music/issues) for problems.

**New**

- **Lyrics source badge**: the lyrics pane now shows the source (embedded, sidecar, online, manual) and format (LRC, TTML, Text) in a small badge so you can tell where the lyrics came from.
- Includes the 0.2.88 downloads-by-artist sort, 0.2.87 per-item recent-search removal and 0.2.86 playlist duration sort.

**Downloads:** Android arm64 APK; Windows x64 installer or portable ZIP; macOS arm64 DMG or ZIP; Linux x64 AppImage or tar.gz. Checksums are in `SHA256SUMS.txt`.
