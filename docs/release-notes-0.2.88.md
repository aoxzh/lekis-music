## English

Lekis Music 0.2.88 preview release, adding artist sorting to downloads. Please [open an issue](https://github.com/aoxzh/lekis-music/issues) for problems.

**New**

- **Sort downloads by artist**: the sort menu can group downloads by artist, then by title within an artist.
- Includes the 0.2.87 per-item recent-search removal, 0.2.86 playlist duration sort and 0.2.85 keyboard-shortcuts help.

**Downloads:** Android arm64 APK; Windows x64 installer or portable ZIP; macOS arm64 DMG or ZIP; Linux x64 AppImage or tar.gz. Checksums are in `SHA256SUMS.txt`.
