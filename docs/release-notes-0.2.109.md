月兔音乐（Lekis Music）0.2.109 预览版，电台本地列表支持排序。有问题欢迎[提 issue](https://github.com/aoxzh/lekis-music/issues)。

## 新增

- **电台本地排序**：收藏、自定义和最近列表可按默认顺序或名称 A–Z / Z–A 排列，与本地搜索配合使用。
- 包含 0.2.108 的歌单随机播放、0.2.107 的歌单合并和 0.2.106 的队列移除重复曲目。

## English

Lekis Music 0.2.109 preview release, adding sorting for saved radio stations. Please [open an issue](https://github.com/aoxzh/lekis-music/issues) for problems.

**New**

- **Sort saved radio stations**: Favorites, Custom and Recent can be ordered by default order or by name A–Z / Z–A, alongside the local search filter.
- Includes the 0.2.108 playlist shuffle, 0.2.107 playlist merge and 0.2.106 queue duplicate removal.

**Downloads:** Android arm64 APK; Windows x64 installer or portable ZIP; macOS arm64 DMG or ZIP; Linux x64 AppImage or tar.gz. Checksums are in `SHA256SUMS.txt`.
