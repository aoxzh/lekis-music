月兔音乐（Lekis Music）0.2.103 预览版，电台的收藏、自定义和最近列表支持本地搜索。有问题欢迎[提 issue](https://github.com/aoxzh/lekis-music/issues)。

## 新增

- **电台本地搜索**：收藏、自定义和最近三个分类支持按名称、国家、语言或标签即时过滤，结果为空时可一键清除。
- 包含 0.2.102 的清除未播放曲目、0.2.101 的歌单清理缺失曲目和 0.2.100 的移除重复曲目。

## English

Lekis Music 0.2.103 preview release, adding local search to saved radio stations. Please [open an issue](https://github.com/aoxzh/lekis-music/issues) for problems.

**New**

- **Local radio search**: Favorites, Custom, and Recent now filter instantly by name, country, language, or tag, with a one-tap clear when nothing matches.
- Includes the 0.2.102 clear-upcoming queue action, 0.2.101 missing-playlist-track cleanup and 0.2.100 duplicate removal.

**Downloads:** Android arm64 APK; Windows x64 installer or portable ZIP; macOS arm64 DMG or ZIP; Linux x64 AppImage or tar.gz. Checksums are in `SHA256SUMS.txt`.
