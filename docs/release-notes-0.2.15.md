## 新增

- **搜索结果分类筛选**：当歌曲 / 专辑 / 艺人中有多组结果时，结果顶部出现「全部 / 歌曲 / 专辑 / 艺人」筛选标签并显示数量；输入新关键词时自动回到「全部」。
- 包含 0.2.14 的最近搜索、0.2.13 的歌词偏移快捷调整和 0.2.12 的迷你播放器增强。

## English

Lekis Music 0.2.15 preview release, adding category filters to search results so phones no longer have to scroll through every group. Please [open an issue](https://github.com/aoxzh/lekis-music/issues) for problems.

**New**

- **Search result filters**: when more than one of Songs / Albums / Artists has hits, chips for "All / Songs / Albums / Artists" (with counts) appear above the results. Typing a new query returns to "All".
- Includes the 0.2.14 recent searches, the 0.2.13 quick lyric-offset actions, and the 0.2.12 mini-player improvements.

**Downloads:** Android arm64 APK; Windows x64 installer or portable ZIP; macOS arm64 DMG or ZIP; Linux x64 AppImage or tar.gz. Checksums are in `SHA256SUMS.txt`.
