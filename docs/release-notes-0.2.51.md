## 新增

- **下载列表筛选**：下载页新增「全部 / 队列 / 失败 / 已下载」筛选标签和数量，下载很多时可直接切到失败或已完成；筛选后没有内容会显示提示。
- 包含 0.2.50 的搜索结果一键播放、0.2.49 的队列曲目添加到歌单和 0.2.48 的艺人页展开全部歌曲。

## English

Lekis Music 0.2.51 preview release, adding status filters to the downloads list. Please [open an issue](https://github.com/aoxzh/lekis-music/issues) for problems.

**New**

- **Downloads filters**: All / Queue / Failed / Downloaded chips with counts make large download libraries easy to narrow down; an empty filter shows a short notice.
- Includes the 0.2.50 play-all search results, 0.2.49 queue-to-playlist and 0.2.48 expandable artist songs.

**Downloads:** Android arm64 APK; Windows x64 installer or portable ZIP; macOS arm64 DMG or ZIP; Linux x64 AppImage or tar.gz. Checksums are in `SHA256SUMS.txt`.
