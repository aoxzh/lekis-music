## 新增

- **复制智能歌单**：智能歌单的更多菜单现在也可复制，新歌单会保留原规则；规则读取或创建失败时会清理残留并提示。
- 包含 0.2.65 的歌单排序、0.2.64 的下载进度节流和 0.2.63 的下载搜索。

## English

Lekis Music 0.2.66 preview release, adding smart-playlist duplication. Please [open an issue](https://github.com/aoxzh/lekis-music/issues) for problems.

**New**

- **Duplicate a smart playlist**: smart playlists can now be duplicated from the More menu while keeping their original rules; failures clean up the partial copy and report the error.
- Includes the 0.2.65 playlist sorting, 0.2.64 throttled download progress and 0.2.63 download search.

**Downloads:** Android arm64 APK; Windows x64 installer or portable ZIP; macOS arm64 DMG or ZIP; Linux x64 AppImage or tar.gz. Checksums are in `SHA256SUMS.txt`.
