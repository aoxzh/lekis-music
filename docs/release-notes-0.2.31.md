月兔音乐（Lekis Music）0.2.31 预览版，桌面播放栏可以一键切换独占模式。有问题欢迎[提 issue](https://github.com/aoxzh/lekis-music/issues)。

## 新增

- **播放栏独占模式快捷开关**：当前输出设备支持独占模式时，桌面播放栏新增 HQ 按钮，一键在共享 / 独占之间切换；不支持独占的设备不显示该按钮。
- 包含 0.2.30 的来源列表直达音源详情、0.2.29 的睡眠定时延长和 0.2.28 的强调色预设。

## English

Lekis Music 0.2.31 preview release, adding a one-click exclusive-mode toggle to the desktop player bar. Please [open an issue](https://github.com/aoxzh/lekis-music/issues) for problems.

**New**

- **Exclusive mode in the player bar**: when the current output device supports exclusive mode, a HQ button appears in the desktop player bar and switches between shared and exclusive output. It is hidden for devices without exclusive support.
- Includes the 0.2.30 source list → source detail link, the 0.2.29 sleep-timer extension and 0.2.28 accent presets.

**Downloads:** Android arm64 APK; Windows x64 installer or portable ZIP; macOS arm64 DMG or ZIP; Linux x64 AppImage or tar.gz. Checksums are in `SHA256SUMS.txt`.
