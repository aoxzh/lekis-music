## 新增

- **最近搜索**：搜索页在空查询时显示最近 8 条搜索词，点击即可重新搜索，也可一键清除。只在按回车提交时记录，输入过程中不会写入；保存在本地设置里，重启后仍在。
- 包含 0.2.13 的歌词偏移快捷调整、0.2.12 的迷你播放器增强，以及 0.2.11 的扫描并行读标签。

## English

Lekis Music 0.2.14 preview release, adding recent searches so frequently used queries are one tap away. Please [open an issue](https://github.com/aoxzh/lekis-music/issues) for problems.

**New**

- **Recent searches**: when the query is empty, the Search page shows the last 8 submitted searches. Tap one to run it again, or clear the list. Only Enter submissions are recorded (not every keystroke), and the list is stored in local settings so it survives restarts.
- Includes the 0.2.13 quick lyric-offset actions, the 0.2.12 mini-player improvements, and the 0.2.11 parallel tag reads.

**Downloads:** Android arm64 APK; Windows x64 installer or portable ZIP; macOS arm64 DMG or ZIP; Linux x64 AppImage or tar.gz. Checksums are in `SHA256SUMS.txt`.
