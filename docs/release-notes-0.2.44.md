月兔音乐（Lekis Music）0.2.44 预览版，下载失败记录可以一键清理。有问题欢迎[提 issue](https://github.com/aoxzh/lekis-music/issues)。

## 新增

- **清理失败下载**：下载页的批量菜单现在可以清理失败记录，不会删除已完成的离线文件；菜单只在确有失败项时出现。
- 包含 0.2.43 的复制歌单、0.2.42 的歌词翻译开关和 0.2.41 的队列保存为歌单。

## English

Lekis Music 0.2.44 preview release, adding a clear-failed-downloads action. Please [open an issue](https://github.com/aoxzh/lekis-music/issues) for problems.

**New**

- **Clear failed downloads**: the Downloads batch menu can now remove failed records without touching completed offline files; the item only appears when failures exist.
- Includes the 0.2.43 duplicate playlist, 0.2.42 lyric translation switch and 0.2.41 save queue as playlist.

**Downloads:** Android arm64 APK; Windows x64 installer or portable ZIP; macOS arm64 DMG or ZIP; Linux x64 AppImage or tar.gz. Checksums are in `SHA256SUMS.txt`.
