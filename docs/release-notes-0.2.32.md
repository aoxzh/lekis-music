## English

Lekis Music 0.2.32 preview release, adding adjustable lyric text size. Please [open an issue](https://github.com/aoxzh/lekis-music/issues) for problems.

**New**

- **Lyrics text size**: Settings → Lyrics now offers Small / Normal / Large / Extra large, applied to both the classic scroll view and the word-by-word stage. The choice is stored in `ui.lyrics_font_scale` and survives restarts.
- Includes the 0.2.31 player-bar exclusive-mode toggle, 0.2.30 source-list → source-detail link and 0.2.29 sleep-timer extension.

**Downloads:** Android arm64 APK; Windows x64 installer or portable ZIP; macOS arm64 DMG or ZIP; Linux x64 AppImage or tar.gz. Checksums are in `SHA256SUMS.txt`.
