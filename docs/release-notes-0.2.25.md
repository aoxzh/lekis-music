## English

Lekis Music 0.2.25 preview release, adding a quick equalizer entry on Now Playing. Please [open an issue](https://github.com/aoxzh/lekis-music/issues) for problems.

**New**

- **Equalizer from Now Playing**: the bottom action row now has an equalizer button, so the 10-band EQ and headphone presets are one tap away without returning to Settings.
- Includes the 0.2.24 scan-all-sources button, 0.2.23 quality-badge source list / copy path and 0.2.22 source list.

**Downloads:** Android arm64 APK; Windows x64 installer or portable ZIP; macOS arm64 DMG or ZIP; Linux x64 AppImage or tar.gz. Checksums are in `SHA256SUMS.txt`.
