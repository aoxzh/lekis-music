## English

Lekis Music 0.2.53 preview release, adding copy-lyrics from Now Playing. Please [open an issue](https://github.com/aoxzh/lekis-music/issues) for problems.

**New**

- **Copy lyrics**: the Now Playing More menu can copy the lyrics as plain text without timestamps; it reports when a track has no lyrics and shows the error if copying fails.
- Includes the 0.2.52 genre download-all, 0.2.51 downloads filters and 0.2.50 play-all search results.

**Downloads:** Android arm64 APK; Windows x64 installer or portable ZIP; macOS arm64 DMG or ZIP; Linux x64 AppImage or tar.gz. Checksums are in `SHA256SUMS.txt`.
