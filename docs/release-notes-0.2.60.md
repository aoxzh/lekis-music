## English

Lekis Music 0.2.60 preview release, adding download-row actions and failure details. Please [open an issue](https://github.com/aoxzh/lekis-music/issues) for problems.

**New**

- **Download row actions**: long-press (or right-click on desktop) a download to copy its cached file path, open the album, or open the artist; failed downloads now show the core's error reason inline.
- Includes the 0.2.59 album/artist durations, 0.2.58 playlist duration and 0.2.57 bulk-play downloads.

**Downloads:** Android arm64 APK; Windows x64 installer or portable ZIP; macOS arm64 DMG or ZIP; Linux x64 AppImage or tar.gz. Checksums are in `SHA256SUMS.txt`.
