月兔音乐（Lekis Music）0.2.76 预览版，下载文件可以在系统文件夹中定位。有问题欢迎[提 issue](https://github.com/aoxzh/lekis-music/issues)。

## 新增

- **下载文件定位**：下载行长按/右键菜单新增「在文件夹中显示」，支持 Windows/macOS/Linux；手机端隐藏。
- 包含 0.2.75 的复制歌单、0.2.74 的图片缓存管理和 0.2.73 的队列下载管理。

## English

Lekis Music 0.2.76 preview release, adding "show in folder" for downloads. Please [open an issue](https://github.com/aoxzh/lekis-music/issues) for problems.

**New**

- **Reveal a download in the file manager**: the download row's long-press/right-click sheet can show the cached file in Explorer/Finder/file manager on desktop; the action is hidden on phones.
- Includes the 0.2.75 copy playlist, 0.2.74 image-cache management and 0.2.73 queue download management.

**Downloads:** Android arm64 APK; Windows x64 installer or portable ZIP; macOS arm64 DMG or ZIP; Linux x64 AppImage or tar.gz. Checksums are in `SHA256SUMS.txt`.
