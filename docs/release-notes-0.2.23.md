## 新增

- **音质标签可直接点开来源**：正在播放的艺人 · 专辑行尾部的音质标签现在可以点击，打开与「更多 → 查看来源」相同的来源列表。
- **来源路径可复制**：来源列表每一行新增复制按钮，方便把本地 / NAS / 媒体服务器路径粘贴到文件管理器或日志里。
- 包含 0.2.22 的来源列表、0.2.21 的下一首封面预取和 0.2.20 的队列长按菜单。

## English

Lekis Music 0.2.23 preview release, making the quality badge open the source list and adding copy-path actions to each source. Please [open an issue](https://github.com/aoxzh/lekis-music/issues) for problems.

**New**

- **Quality badge opens sources**: the quality label at the end of the artist · album line in Now Playing is now tappable and opens the same source list as "More → View Sources".
- **Copy source path**: each source row has a copy button for pasting local / NAS / media-server paths into a file manager or a log.
- Includes the 0.2.22 source list, 0.2.21 next-cover prefetch and 0.2.20 queue long-press menu.

**Downloads:** Android arm64 APK; Windows x64 installer or portable ZIP; macOS arm64 DMG or ZIP; Linux x64 AppImage or tar.gz. Checksums are in `SHA256SUMS.txt`.
