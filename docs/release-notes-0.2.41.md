月兔音乐（Lekis Music）0.2.41 预览版，播放队列可以保存为新歌单。有问题欢迎[提 issue](https://github.com/aoxzh/lekis-music/issues)。

## 新增

- **播放队列保存为歌单**：队列标题栏的更多菜单可把当前队列按顺序保存为新歌单，过程中显示进度和失败数量；空队列或全部曲目无法解析时会提示，不会留下空歌单。
- 包含 0.2.40 的复制曲目信息、0.2.39 的清理已完成下载和 0.2.38 的歌词偏移浮条。

## English

Lekis Music 0.2.41 preview release, adding save-queue-as-playlist. Please [open an issue](https://github.com/aoxzh/lekis-music/issues) for problems.

**New**

- **Save the queue as a playlist**: the queue header's More menu can save the current queue, in order, as a new playlist. A progress dialog and failure count are shown; empty queues or unrecoverable tracks are reported and no empty playlist is left behind.
- Includes the 0.2.40 copy track info, 0.2.39 clear completed downloads and 0.2.38 quick lyric-offset bar.

**Downloads:** Android arm64 APK; Windows x64 installer or portable ZIP; macOS arm64 DMG or ZIP; Linux x64 AppImage or tar.gz. Checksums are in `SHA256SUMS.txt`.
