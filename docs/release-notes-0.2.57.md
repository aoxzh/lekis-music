月兔音乐（Lekis Music）0.2.57 预览版，离线库可以一键全部播放或随机播放。有问题欢迎[提 issue](https://github.com/aoxzh/lekis-music/issues)。

## 新增

- **批量播放已下载**：下载页批量菜单新增「播放已下载 / 随机播放已下载」，离线库可以整队列播放。
- 包含 0.2.56 的下载整行点击播放、0.2.55 的歌曲库一键播放和 0.2.54 的 Windows 托盘当前歌曲。

## English

Lekis Music 0.2.57 preview release, adding bulk play for the offline library. Please [open an issue](https://github.com/aoxzh/lekis-music/issues) for problems.

**New**

- **Play the offline library**: the Downloads batch menu now offers Play Downloaded and Shuffle Downloaded, queueing every completed download.
- Includes the 0.2.56 tap-a-download-to-play, 0.2.55 library play-all and 0.2.54 Windows tray now-playing tooltip.

**Downloads:** Android arm64 APK; Windows x64 installer or portable ZIP; macOS arm64 DMG or ZIP; Linux x64 AppImage or tar.gz. Checksums are in `SHA256SUMS.txt`.
