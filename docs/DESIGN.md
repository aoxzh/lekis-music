# Lekis 视觉与交互方向

> 状态：v0.3（2026-11-20）。依据 [REQUIREMENTS.md](REQUIREMENTS.md) §3.5。
>
> v0.2 提出的"月夜视觉系统 + 三个参照产品"已基本落地（第 4 节）。在此基础上又加了液态玻璃 / 扁平两种 TabBar、Haze 式封面模糊 + 噪点背景、浮动迷你播放器、Flow / Steps / Tilt 歌词舞台。
> 参照的是交互逻辑与信息架构，不是皮肤。
>
> **正在改（未合入，见 [HANDOFF.md](HANDOFF.md)）**：
> - 歌词默认改成 Apple Music 式经典歌词（大号逐行聚焦、非当前行降透明度），歌词舞台变成可选，并参照 [mygo-music](https://github.com/egoist/mygo-music) 重新设计（只借鉴交互，AGPL 代码不拷）。
> - 桌面布局按 Spotify / Apple Music 桌面端重组：左侧导航 + 中间内容 + 右侧上下文栏（第 2.4 节 expanded 布局）。
> - 设置分成"基本"和"高级"两层，常用项放外面，独占输出 / ReplayGain / 听歌记录 / 插件 / 备份 / 日志收进"高级"。

## 1. 借鉴矩阵

| 维度 | 参照 | 拿什么 | 为什么有效 | 明确不拿 |
|---|---|---|---|---|
| 播放页氛围 | Apple Music | 封面取色生成弥散背景；大号、逐行聚焦的歌词；队列常驻在同一屏 | 播放页的本质是沉浸感。背景从内容里“长出来”，大号歌词把注意力收束到一处，队列不弹窗打断 | 双滑块（进度 + 音量）紧邻；Apple 的具体控件外观、图标与比例 |
| 信息架构 | Spotify 桌面端 | 左导航 + 中内容 + 右侧上下文（正在播放 / 队列 / 歌词）；首页横向卡片流 | 音乐库是“边浏览边听”的任务，左侧稳定导航、右侧常驻上下文能显著降低来回跳转成本 | 播放页下方堆播客、周边商品、社交动态；为停留时长而拥挤的信息流 |
| 内容发现 | YouTube Music | 顶部场景 / 情绪筛选胶囊；播放页保留音频 / 视频切换位 | 解决“不知道听什么”的冷启动；胶囊是低成本过滤，音视频切换为 MV / Live 预留 | 类短视频的竖屏信息流、视频化的底部 Tab；把音乐工具做成内容消费 App |
| 品牌识别 | 自有 | 月夜靛紫 + 月光金；靛紫做交互，金色只做“月光”点缀；自绘图标语言；封面是画面里最大的东西 | 和 Apple Music 的白色玻璃、Spotify 的绿色块面明确区分；暗色是默认，不是附属主题 | 照搬任何一家的品牌色、图标、布局比例 |

三条“避坑”直接写进验收：**不出现双滑块、不堆信息流、不做短视频 Tab。**

## 2. 月夜视觉系统

### 2.1 颜色

暗色是默认主题：深靛蓝的夜色背景，冷白文字。主色仍是月夜靛紫（可操作、选中、主按钮），
月光金只出现在“正在发生 / 品牌标记”这样的少数位置；封面调色板负责大面积氛围。

| Token | Dark | Light | 用途 |
|---|---|---|---|
| background | `#08070F` | `#F8F7FC` | 页面底色 |
| surface | `#0F0E17` | `#FFFFFF` | 面板、播放条 |
| surfaceVariant | `#181624` | `#EFEDF7` | 输入框、次级块 |
| surfaceElevated | `#14121E` | `#FFFFFF` | 浮层、卡片 |
| onSurface | `#F4F1FA` | `#17151F` | 主文字（冷白 / 墨） |
| onSurfaceVariant | `#A5A1B5` | `#615D70` | 元信息 |
| outline | `#29263A` | `#DEDAE9` | 1px 分隔 |
| accent | `#6E5BF0` | `#4F46C8` | 播放、选中、主按钮（月夜靛紫） |
| accentSoft | `#221D3F` | `#E8E5FF` | 选中底、悬浮底 |
| moon | `#F2C46B` | `#B9821F` | 月光高光 / 品牌标记 / 正在播放 |
| aurora | `#79D6C2` | `#1F7A6B` | 次级强调（同步、成功） |
| danger | `#FF6B81` | `#C03A4E` | 错误 |

纯黑 OLED 只覆盖 background / surface / surfaceVariant / surfaceElevated。

### 2.2 字体与排版

不引入网络字体。用系统字体，但通过字号、字重、字距建立编辑感：

- Display 36/42，w700，字距 -0.6 —— 页面主标题、播放页曲名。
- Title 28/34，w700，字距 -0.3；Title2 22/28，w600。
- 正文 15/21；元信息 11/15，字距 +0.3，作为“微标签”。
- 歌词 32/40，w700；非当前行透明度 0.35 + 1.5px 模糊。
- 中文不强行拉字距；西文与数字使用等宽数字（时间、计数）。

### 2.3 形状、层次与动效

- 封面角 12，卡片 18，按钮 14，胶囊 999。按钮不再全部是 Material 默认的 Stadium。
- 不用投影堆层次：用 **1px 半透明描边 + 封面模糊光晕 + 半透明面板**。
- 弹簧参数沿用 `design/tokens.json`；封面转场用共享元素；背景渐变 24s 无缝循环；
  切歌 900ms 交叉淡入；减少动效时全部退化为静态模糊。
- 触控目标 48dp 起；手机只保留一条进度条，音量交给系统键。
- 大封面（正在播放、专辑页头）圆角按边长的 6%（`radius.artworkFraction`），任何尺寸形状一致；
  网格 / 列表里的小封面仍用固定 12 / 6。
- 迷你播放器浮动：胶囊形，和 TabBar 共用同一块玻璃材质（液态 / 扁平跟随 TabBar 设置）；四周 8 外边距；贴窗口底边时自己让开手势区 / 小白条。
- 转场：迷你播放器 → 正在播放是容器展开（边界、圆角、内容交叉淡入一起走弹簧），
  上拉可跟手展开、下拉可跟手收回；专辑封面 → 专辑页是共享元素，飞行中圆角与阴影插值；
  列表行按住时轻微下沉（0.98）叠加水波纹。

### 2.4 布局骨架

```
compact   ┌──────────────────────┐
          │ content              │
          ├──────────────────────┤
          │ mini player (浮动)   │
          │ bottom tabs          │
          └──────────────────────┘

medium    ┌────┬─────────────────┐
          │rail│ content         │
          │    │                 │
          ├────┴─────────────────┤
          │ player bar           │
          └──────────────────────┘

expanded  ┌────────┬──────────────┬──────────────┐
          │sidebar │ content      │ context      │
          │ 248    │ flexible     │ 320 (可选)   │
          ├────────┴──────────────┴──────────────┤
          │ player bar + volume                  │
          └──────────────────────────────────────┘
```

- 右侧上下文栏只在 `>= 1200dp` 且“有正在播放 / 打开了歌词或队列”时出现；
  它承载队列、歌词、艺人信息，避免播放页反复弹窗。
- 折叠屏：继续用 `AdaptiveTwoPane`，分栏落在铰链上；半折叠书式 = 左右，
  桌面式 = 上下，内容绝不压折痕。

## 3. 页面映射

### 首页

- 顶部是“今晚听什么”式的问候 + 微标签，而不是一个 AppBar 标题。
- 第一屏是 **继续收听 hero**：封面模糊铺底 + 大封面 + 曲名 + 一键继续。
- 下面是横向卡片流：最近添加、最常播放、为你混音（数据就绪后）。
- 情绪 / 场景胶囊（专注、通勤、夜晚、运动）在 P1 接本地标签与播放统计后出现；
  没有真实数据前不摆假胶囊。
- 卡片 2:3 或 1:1，hover 轻微抬起，按下缩放；点击专辑优先进入详情而不是直接播放。

### 资料库

- 宽屏保持“列表 | 详情”双栏；手机是推入详情。
- 顶部分段改成胶囊式 segment，排序收进图标菜单。
- 大列表虚拟化 + 字母 / 拼音索引；密度比首页高，信息优先。

### 正在播放

- 全屏、无 AppBar：封面、曲名、一条进度、播放控制。
- 背景：封面模糊（半径 160）铺满 → 调色板流动渐变半透明叠加 → 35% 压暗（深色字时提亮）保护对比度
  → 极淡颗粒防色带。低电量 / 减少动效时去掉流动层，只剩静态模糊。
- 横向或近方形窗口、竖向折痕：分区并排——封面 | 控制；打开歌词时封面 + 控制 | 歌词，
  ≥1200 宽时封面 | 控制 | 歌词。有竖向折痕 / 铰链时分界线正好落在折痕上。
- 竖屏：封面在上、控制在下，歌词替换封面；平板竖屏限制内容宽度。
- 半折叠桌面式：上半封面 / 歌词，下半控制，折痕留空。
- 手势：下滑关闭，封面左右滑切歌、单击播放 / 暂停；点击歌词行跳转。
- 歌词：LRC / 增强 LRC / TTML 同步滚动并高亮当前行，同时间戳的第二行作为翻译显示在下方；
  纯文本静态可选中；查找中（可能要等在线结果）显示“正在查找歌词…”，没有时显示“暂无歌词”。
- 队列入口常驻但不遮挡内容；手机是底部抽屉，桌面是右栏。

### 音源 / 设置

- 明确是“后台”页面：更安静、更密、更少动效，但仍使用同一套排版与颜色。
- 空状态只放品牌标记（兔子）+ 一句明确的下一步，不用 Material 图标。
- 扫描进度、错误、权限说明都贴着对应的源展示，不弹全局对话框。

## 4. 实施情况

**已完成**：月夜色板 / 字距 / 圆角 / 按钮形状（`app/lib/src/theme/`）；品牌化侧边栏和 Tab（液态玻璃 / 扁平两种，设置里切换）；播放条和浮动迷你播放器统一材质；空状态只放品牌标记 + 一句下一步；首页问候 + 继续收听 + 横向卡片；播放页封面比例、取色模糊背景、歌词对比度；桌面右侧队列面板、手机队列抽屉；封面墙；封面左右滑切歌；专辑封面 → 专辑页共享元素转场；迷你播放器上拉 / 正在播放下拉跟手。

本地封面：扫描结束后由核心补填内嵌封面；侧车 `cover.jpg` / `folder.jpg` 在 Android 上需要"照片和视频"权限（`READ_MEDIA_IMAGES`），拒绝时仍可用内嵌封面；没有封面的专辑用按专辑确定性的渐变占位图。

**还没做**：

1. 队列拖拽排序 / 删除。
2. 情绪 / 场景胶囊（接本地流派、年代、播放统计；没有真实数据前不摆假胶囊）。
3. 桌面悬浮歌词、置顶迷你播放器（`UIX-07/08`）。
4. P2：音视频切换、频谱可视化、DJ 模式。

## 5. 验收

- 在 Fold5 上验证：展开双栏、外屏单栏、半折叠书式 / 桌面式、横竖屏。
- 120Hz 下滚动与渐变不掉帧；减少动效时无持续动画。
- 文本对比度达到 WCAG AA；触控目标 >= 48dp。
- 全应用只有一条进度滑块；手机不出现音量滑块。
- 不出现信息流式堆叠、短视频 Tab、照搬参照产品的控件。
