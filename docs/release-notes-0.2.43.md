月兔音乐（Lekis Music）0.2.43 预览版，普通歌单可以一键复制成新歌单。有问题欢迎[提 issue](https://github.com/aoxzh/lekis-music/issues)。

## 新增

- **复制歌单**：普通歌单的更多菜单可复制为「原名 副本」，按顺序写入并显示进度；智能歌单不提供直接复制，避免把规则歌单误变成静态快照。
- 包含 0.2.42 的歌词翻译开关、0.2.41 的队列保存为歌单和 0.2.40 的复制曲目信息。

## English

Lekis Music 0.2.43 preview release, adding playlist duplication. Please [open an issue](https://github.com/aoxzh/lekis-music/issues) for problems.

**New**

- **Duplicate playlist**: a regular playlist's More menu can copy it as "Name copy", preserving order and showing progress. Smart playlists intentionally do not offer direct duplication, so rule-based playlists are not silently turned into static snapshots.
- Includes the 0.2.42 lyric translation switch, 0.2.41 save queue as playlist and 0.2.40 copy track info.

**Downloads:** Android arm64 APK; Windows x64 installer or portable ZIP; macOS arm64 DMG or ZIP; Linux x64 AppImage or tar.gz. Checksums are in `SHA256SUMS.txt`.
