月兔音乐（Lekis Music）0.2.30 预览版，「查看来源」里的音源行可以直接打开音源详情。有问题欢迎[提 issue](https://github.com/aoxzh/lekis-music/issues)。

## 新增

- **来源列表直达音源详情**：在「查看来源」里点击任意一行可打开对应音源的详情页，查看凭据、扫描状态或直接重新扫描，不再需要先退出正在播放再找音源。
- 包含 0.2.29 的睡眠定时延长 / 按需计时、0.2.28 的强调色预设和 0.2.27 的歌词下一首预取。

## English

Lekis Music 0.2.30 preview release, letting source rows in "View Sources" open the source detail page. Please [open an issue](https://github.com/aoxzh/lekis-music/issues) for problems.

**New**

- **Sources list to source detail**: tapping a row in "View Sources" opens that source's detail page, where credentials and scan status are visible and a rescan can be started without leaving Now Playing and hunting for the source.
- Includes the 0.2.29 sleep-timer extension / on-demand ticking, 0.2.28 accent presets and 0.2.27 next-lyrics prefetch.

**Downloads:** Android arm64 APK; Windows x64 installer or portable ZIP; macOS arm64 DMG or ZIP; Linux x64 AppImage or tar.gz. Checksums are in `SHA256SUMS.txt`.
