月兔音乐（Lekis Music）0.2.116 预览版，长列表点击任意一首都会播放完整队列。有问题欢迎[提 issue](https://github.com/aoxzh/lekis-music/issues)。

## 改进

- **长列表从任意位置播放完整队列**：在资料库歌曲、喜欢的歌曲、流派和文件夹列表中点击任意一首，都会由核心展开完整列表并从该位置开播，不再只播放已加载的几页。
- 包含 0.2.115 的启动并行初始化、0.2.114 的资料库多选加入歌单和 0.2.113 的喜欢页保存为歌单。

## English

Lekis Music 0.2.116 preview release, playing the full list from any tapped row. Please [open an issue](https://github.com/aoxzh/lekis-music/issues) for problems.

**Improved**

- **Play the full queue from any row in long lists**: tapping a song in the library, Liked Songs, a genre or a folder now asks the core to expand the complete list and start at that position, instead of only queueing the loaded pages.
- Includes the 0.2.115 parallel startup initialization, 0.2.114 library multi-select add-to-playlist and 0.2.113 Liked Songs save-as-playlist.

**Downloads:** Android arm64 APK; Windows x64 installer or portable ZIP; macOS arm64 DMG or ZIP; Linux x64 AppImage or tar.gz. Checksums are in `SHA256SUMS.txt`.
