## 新增

- **清除未播放曲目**：播放队列菜单可只清除当前曲目之后的条目，当前播放不中断；带确认提示。
- 包含 0.2.101 的歌单清理缺失曲目、0.2.100 的移除重复曲目和 0.2.99 的搜索结果加载更多。

## English

Lekis Music 0.2.102 preview release, letting you clear only upcoming queue tracks. Please [open an issue](https://github.com/aoxzh/lekis-music/issues) for problems.

**New**

- **Clear upcoming tracks**: the queue menu can remove everything after the current track without interrupting playback, behind a confirmation dialog.
- Includes the 0.2.101 missing-playlist-track cleanup, 0.2.100 duplicate removal and 0.2.99 search load-more.

**Downloads:** Android arm64 APK; Windows x64 installer or portable ZIP; macOS arm64 DMG or ZIP; Linux x64 AppImage or tar.gz. Checksums are in `SHA256SUMS.txt`.
