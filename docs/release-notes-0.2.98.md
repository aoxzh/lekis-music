Lekis Music 0.2.98 preview release, caching search results briefly. Please [open an issue](https://github.com/aoxzh/lekis-music/issues) for problems.

**Performance**

- **Search-result cache**: library and source search results are cached for 30 seconds so returning to the search page reuses them; catalog changes still invalidate the cache.

**Downloads:** Android arm64 APK; Windows x64 installer or portable ZIP; macOS arm64 DMG or ZIP; Linux x64 AppImage or tar.gz. Checksums are in `SHA256SUMS.txt`.
