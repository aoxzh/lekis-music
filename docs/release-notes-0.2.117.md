月兔音乐（Lekis Music）0.2.117 预览版，歌单可以多选批量移除条目。有问题欢迎[提 issue](https://github.com/aoxzh/lekis-music/issues)。

## 新增

- **歌单多选批量移除**：歌单菜单可进入批量选择，长按或点击勾选多个条目后一次移除，带确认、进度和失败数量。
- 包含 0.2.116 的长列表播放完整队列、0.2.115 的启动并行初始化和 0.2.114 的资料库多选加入歌单。

## English

Lekis Music 0.2.117 preview release, adding multi-select batch removal to playlists. Please [open an issue](https://github.com/aoxzh/lekis-music/issues) for problems.

**New**

- **Batch remove playlist entries**: the playlist menu enters selection mode; long-press or tap to select multiple entries and remove them at once, with confirmation, progress and a failure count.
- Includes the 0.2.116 full-queue playback from long lists, 0.2.115 parallel startup initialization and 0.2.114 library multi-select add-to-playlist.

**Downloads:** Android arm64 APK; Windows x64 installer or portable ZIP; macOS arm64 DMG or ZIP; Linux x64 AppImage or tar.gz. Checksums are in `SHA256SUMS.txt`.
