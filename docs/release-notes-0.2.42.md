## 新增

- **歌词翻译开关**：设置 → 歌词新增「显示歌词翻译」。关闭后经典滚动和逐字舞台只显示原文，字号、偏移等设置保持不变；带翻译/罗马音的歌词默认仍显示。
- 包含 0.2.41 的队列保存为歌单、0.2.40 的复制曲目信息和 0.2.39 的清理已完成下载。

## English

Lekis Music 0.2.42 preview release, adding a show-translations switch for lyrics. Please [open an issue](https://github.com/aoxzh/lekis-music/issues) for problems.

**New**

- **Lyric translation switch**: Settings → Lyrics now has "Show lyric translations". Turning it off hides translations/romanisation in both the classic scroll and word-by-word stage while keeping size/offset settings; translated lyrics still show by default.
- Includes the 0.2.41 save queue as playlist, 0.2.40 copy track info and 0.2.39 clear completed downloads.

**Downloads:** Android arm64 APK; Windows x64 installer or portable ZIP; macOS arm64 DMG or ZIP; Linux x64 AppImage or tar.gz. Checksums are in `SHA256SUMS.txt`.
