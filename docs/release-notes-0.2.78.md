月兔音乐（Lekis Music）0.2.78 预览版，歌单条目可以直接移到顶部或底部。有问题欢迎[提 issue](https://github.com/aoxzh/lekis-music/issues)。

## 新增

- **歌单条目移到顶部/底部**：歌单条目菜单新增「移到顶部 / 移到底部」，长歌单不必多次上移/下移。
- 包含 0.2.77 的下载排序、0.2.76 的在文件夹中显示和 0.2.75 的复制歌单。

## English

Lekis Music 0.2.78 preview release, adding move-to-top / move-to-bottom for playlist entries. Please [open an issue](https://github.com/aoxzh/lekis-music/issues) for problems.

**New**

- **Move a playlist entry to the top or bottom**: the entry menu can jump straight to either end, so long playlists no longer require repeated up/down moves.
- Includes the 0.2.77 downloads sorting, 0.2.76 show-in-folder and 0.2.75 copy playlist.

**Downloads:** Android arm64 APK; Windows x64 installer or portable ZIP; macOS arm64 DMG or ZIP; Linux x64 AppImage or tar.gz. Checksums are in `SHA256SUMS.txt`.
