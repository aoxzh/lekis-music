月兔音乐（Lekis Music）0.2.119 预览版，播放历史可以批量加入歌单或下载。有问题欢迎[提 issue](https://github.com/aoxzh/lekis-music/issues)。

## 新增

- **播放历史批量加入歌单与下载**：历史页新增「加入歌单」和「下载全部」，可把当前列表（含搜索过滤结果）加入已有歌单或整组下载。
- 包含 0.2.118 的搜索结果批量保存/下载、0.2.117 的歌单多选批量移除和 0.2.116 的长列表播放完整队列。

## English

Lekis Music 0.2.119 preview release, adding batch add-to-playlist and download for playback history. Please [open an issue](https://github.com/aoxzh/lekis-music/issues) for problems.

**New**

- **Batch add or download from history**: the history page can add the current list (including filtered results) to an existing playlist or queue every missing track for download.
- Includes the 0.2.118 search result batch save/download, 0.2.117 playlist multi-select batch removal and 0.2.116 full-queue playback from long lists.

**Downloads:** Android arm64 APK; Windows x64 installer or portable ZIP; macOS arm64 DMG or ZIP; Linux x64 AppImage or tar.gz. Checksums are in `SHA256SUMS.txt`.
