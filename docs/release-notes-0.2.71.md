## English

Lekis Music 0.2.71 preview release, adding View Album / View Artist to Now Playing. Please [open an issue](https://github.com/aoxzh/lekis-music/issues) for problems.

**New**

- **View Album / Artist from Now Playing**: the More menu now opens the current track's album or artist directly, with a notice when the artist is not in the library.
- Includes the 0.2.70 playback-history actions, 0.2.69 home-shelf actions and 0.2.68 playlist search.

**Downloads:** Android arm64 APK; Windows x64 installer or portable ZIP; macOS arm64 DMG or ZIP; Linux x64 AppImage or tar.gz. Checksums are in `SHA256SUMS.txt`.
