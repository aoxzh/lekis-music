产品：**Lekis Music**（月兔音乐）——跨平台、开箱即用的本地 / NAS 音乐播放器。
技术路线：Rust 核心 + Flutter UI（[ADR-0006](adr/0006-flutter-ui.md)）。平台顺序：Windows、Android 先行，macOS、iOS、Linux 在 Beta 跟进（[ROADMAP.md](ROADMAP.md)）。许可证 MPL-2.0，复用优先（[ADR-0007](adr/0007-license-and-reuse-first.md)）。

## 0. 设计原则

1. **零配置**：装好 → 自动发现局域网 NAS → 选目录 → 开始听。不需要服务器、账号或 Docker。
2. **本地优先、隐私优先**：数据都在用户自己的设备和 NAS 上；不强制注册；遥测默认关闭。
3. **不破坏用户文件**：任何对原文件的写入都要用户明确确认，并且可以撤销。
4. **快**：10 万首歌的库，滚动、搜索、切歌都要"零感知"。
5. **美**：每一屏都要达到能截图发社交媒体的水准。
6. **开放**：兼容 OpenSubsonic / Jellyfin / Plex 生态；数据可导出；插件 API 公开。

### 0.1 非目标（明确不做）

- ❌ 视频、电影、电视剧
- ❌ 官方内置或分发任何第三方流媒体（破解）音源
- ❌ 音乐下载站或资源分享社区
- ❌ 社交网络（只做 Last.fm / ListenBrainz scrobble 和分享卡片）
- ⏸ 有声书：2.0 以后再评估（数据模型预留，不进入 1.0）。播客例外：已决定用它替换网络电台，正在做（见 [HANDOFF.md](HANDOFF.md)），完成后在这里补需求编号

## 2. 核心用户场景

| # | 场景 | 期望体验 |
|---|---|---|
| S1 | 首次安装，家里有群晖 | 启动后 5 秒内列出局域网里的 SMB / WebDAV / DLNA 设备 → 登录 → 选 "Music" 目录 → 边扫描边能播，第一首歌 10 秒内响起 |
| S2 | 歌曲没封面、没歌词 | 后台自动用指纹识别并补全；可信度低的进"待确认"队列，一键确认或换候选 |
| S3 | 出门在外 | 家庭 Wi-Fi 切到 5G 时自动切源：离线缓存 > 自有服务器（转码）> 提示不可用；收藏的歌单可提前离线 |
| S4 | 手机上收藏，回家打开电脑 | 电脑上也已收藏（走 NAS 同步目录，没有服务器） |
| S5 | 在电脑上听歌 | 系统媒体键、任务栏/菜单栏控制、桌面悬浮歌词、迷你播放器全部可用 |
| S6 | 开车 | CarPlay / Android Auto 浏览和播放，支持语音点歌 |
| S7 | 想听"跟这首差不多的" | 一键"由此开始电台"，基于本地声学分析 + 标签生成无限队列 |
| S8 | 发烧友 | 选 USB DAC → 独占 / 比特完美 → 自动切换采样率 → DSD 原生 / DoP |
| S9 | 想听库里没有的歌 | 用户自己装了音源插件时，搜索结果出现"在线"分区；没装就不显示 |
| S10 | 从其他产品迁移 | 导入歌单、播放次数、评分、收藏 |

### 3.3 元数据补全：封面 / 歌词 / 标签（Enrichment）

```
      → ≥ 阈值：自动应用（存覆盖层）    < 阈值：进入"待确认"队列
```

### 3.5 界面与体验（UI/UX）

#### 3.5.1 设计语言

- **内容第一**：封面是主角，界面元素退后。
- **取色系统**：从封面提取主色和辅色，生成**流动的网格渐变背景**（GPU shader，30~60fps，低电量时降级成静态模糊）。
- **字体**：西文用 Inter 或自研，中文默认使用系统字体（苹方 / 思源黑体 / 微软雅黑），支持用户自定义。
- **动效**：统一使用弹簧物理参数；共享元素转场（封面从列表飞到正在播放页）；120Hz 高刷适配。
- **主题**：浅色 / 深色 / 跟随系统 / 纯黑 OLED。
- **自己的品牌识别**：配色、图标、布局比例要和 Apple Music 有明显区别，不照搬它的 UI 元素。

#### 3.5.2 信息架构

| 移动端（底部 Tab）| 桌面端（左侧边栏）|
|---|---|
| **首页**：继续播放、最近添加、为你混音（本地算法）、往年今日、未补全提示 | 首页 / 搜索 |
| **资料库**：歌曲 / 专辑 / 艺人 / 歌单 / 文件夹 / 流派 | 资料库各维度 + 来源分组 |
| **搜索**：本地 + 在线（插件）分区展示 | 歌单列表（可文件夹化）|
| **设置**（放在资料库右上角）| 底部常驻播放栏 + 可展开的右侧队列/歌词面板 |

### 4.2 稳定性

- 崩溃率 ≤ 0.1%（按会话计）；播放中断（非网络原因）≤ 1 次/100 小时。
- 网络抖动时：缓冲区耗尽前自动重连；NAS 断开后恢复连接要保持播放进度。
- 数据库：WAL 模式 + 定期备份；**SQLite 文件绝不放在网络共享上**（[ADR-0004](adr/0004-sqlite-never-on-network-share.md)）。

### 4.3 安全与隐私

- 凭据只存在系统钥匙串中；所有网络请求使用 TLS（rustls），允许用户为自签名的 NAS 证书"信任这一个证书"（证书锁定）。
- 插件运行在沙箱中，权限最小化。
- 不收集个人数据；分析统计默认关闭，打开后也只上报匿名的聚合数据。
- 第三方元数据请求只发送必要字段（艺人/标题/时长/指纹），不发送文件路径。

### 4.4 兼容性（发布前必须测试）

- NAS 兼容矩阵：群晖 DSM 7.x、威联通 QTS/QuTS、飞牛 fnOS、Unraid、TrueNAS SCALE、OpenMediaVault、Windows 共享、macOS 共享、Samba 4.x、Alist/OpenList WebDAV、Nextcloud。
- 服务器兼容：Navidrome（最新两个大版本）、Jellyfin 10.10+、Plex Media Server、Emby、gonic、Ampache。

## 6. 术语

- **Gapless**：无缝播放，曲目之间没有静音间隙。
- **ReplayGain / EBU R128**：响度标准化，让不同歌曲的音量一致。
- **比特完美（Bit-perfect）**：音频数据不经过任何处理，原样送到 DAC。
- **OpenSubsonic**：Subsonic API 的社区扩展标准，Navidrome 等服务器都支持。
- **MBID**：MusicBrainz 的唯一标识符。**AcoustID**：基于音频指纹的识别服务。
- **CRDT / HLC**：无冲突复制数据类型 / 混合逻辑时钟，用于在没有中心服务器的情况下合并多设备的修改。
- **WASM 组件模型 / WIT**：WebAssembly 的模块化接口标准，用于定义插件的接口。
