## 新增

- **播放历史一键播放**：播放历史页顶部显示最近曲目数，并提供播放全部/随机播放；列表仍可点任意一首从该曲开始。
- 包含 0.2.69 的首页歌架播放、0.2.68 的歌单内搜索和 0.2.67 的反转/随机。

## English

Lekis Music 0.2.70 preview release, adding play-all and shuffle to playback history. Please [open an issue](https://github.com/aoxzh/lekis-music/issues) for problems.

**New**

- **Play or shuffle playback history**: the history page header shows the recent-track count plus Play All and Shuffle; tapping any row still starts from that track.
- Includes the 0.2.69 home-shelf actions, 0.2.68 playlist search and 0.2.67 reverse/shuffle order.

**Downloads:** Android arm64 APK; Windows x64 installer or portable ZIP; macOS arm64 DMG or ZIP; Linux x64 AppImage or tar.gz. Checksums are in `SHA256SUMS.txt`.
