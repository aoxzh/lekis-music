月兔音乐（Lekis Music）0.2.85 预览版，桌面端设置里可以查看播放快捷键。有问题欢迎[提 issue](https://github.com/aoxzh/lekis-music/issues)。

## 新增

- **键盘快捷键帮助**：桌面端设置 → 高级新增播放快捷键说明，列出空格、Ctrl/Cmd+方向键、Shift+方向键和媒体键。
- 包含 0.2.84 的专辑页更多来自、0.2.83 的专辑/艺人复制曲目列表和 0.2.82 的用其他应用打开下载。

## English

Lekis Music 0.2.85 preview release, adding a keyboard-shortcuts help dialog on desktop. Please [open an issue](https://github.com/aoxzh/lekis-music/issues) for problems.

**New**

- **Keyboard shortcuts help**: Settings → Advanced on desktop now opens a list of playback shortcuts for Space, Ctrl/Cmd+arrows, Shift+arrows, and media keys.
- Includes the 0.2.84 More by artist shelf, 0.2.83 album/artist copy track list and 0.2.82 open-download-with-app.

**Downloads:** Android arm64 APK; Windows x64 installer or portable ZIP; macOS arm64 DMG or ZIP; Linux x64 AppImage or tar.gz. Checksums are in `SHA256SUMS.txt`.
