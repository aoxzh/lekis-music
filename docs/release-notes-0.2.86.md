## 新增

- **歌单按时长排序**：排序菜单新增「按时长」，可与按标题/艺人/专辑/添加时间等一起使用。
- 包含 0.2.85 的键盘快捷键帮助、0.2.84 的专辑页更多来自和 0.2.83 的专辑/艺人复制曲目列表。

## English

Lekis Music 0.2.86 preview release, adding duration sorting for playlists. Please [open an issue](https://github.com/aoxzh/lekis-music/issues) for problems.

**New**

- **Sort a playlist by duration**: the sort sheet can order tracks by length, alongside title, artist, album and date added.
- Includes the 0.2.85 keyboard-shortcuts help, 0.2.84 More by artist shelf and 0.2.83 album/artist copy track list.

**Downloads:** Android arm64 APK; Windows x64 installer or portable ZIP; macOS arm64 DMG or ZIP; Linux x64 AppImage or tar.gz. Checksums are in `SHA256SUMS.txt`.
