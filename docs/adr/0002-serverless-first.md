# ADR-0002：无服务器优先，NAS 节点可选

- 状态：已采纳
- 日期：2026-11-19
- 相关需求：SRC-01~03、LIB-05、SYN-01~07、NOD-01~09

## 背景

用户不想像 Jellyfin / Plex 那样自己部署后端，但又需要多设备同步，有时还需要远程访问。

## 决策

- 客户端内置完整核心，直接读取本地和 NAS 共享（SMB / WebDAV / NFS / SFTP），**不需要任何服务器就能使用全部核心功能**。
- 多设备同步默认利用 NAS 共享里的 `.lekis/sync/` 目录（每台设备只写自己的子目录，见 ADR-0004 的约束），以后增加局域网 P2P 同步。
- 远程访问、服务端转码、7×24 后台分析由**可选的** `lekis-node` 提供。它和客户端是同一个核心，只是加了 HTTP 服务。

## 后果

- 扫描大量网络文件很慢 → 必须做"部分读取"和"NAS 共享索引"（LIB-05）。
- NAS 共享可能是只读的 → 所有写 `.lekis/` 的功能都要能降级。
- 节点和客户端共用核心，不能把"服务器专用"的逻辑写进领域 crate，要放在 `lekis-node` 里。
