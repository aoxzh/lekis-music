## 新增

- **队列行长按菜单**：长按队列里的曲目可以喜欢 / 取消喜欢、上移 / 下移或从队列移除；不额外占用行内按钮，手机和桌面都可用。
- 包含 0.2.18 的睡眠定时倒计时、0.2.17 的音质标签和 0.2.16 的扫描剩余时间。

## English

Lekis Music 0.2.19 preview release, adding a long-press menu to queue rows for favorite and queue management. Please [open an issue](https://github.com/aoxzh/lekis-music/issues) for problems.

**New**

- **Queue row long-press menu**: long-press a queue row to like/unlike it, move it up/down, or remove it from the queue. It adds no extra inline buttons and works on both phones and desktop.
- Includes the 0.2.18 sleep-timer countdown, 0.2.17 audio-quality badge, and 0.2.16 remaining scan time.

**Downloads:** Android arm64 APK; Windows x64 installer or portable ZIP; macOS arm64 DMG or ZIP; Linux x64 AppImage or tar.gz. Checksums are in `SHA256SUMS.txt`.
