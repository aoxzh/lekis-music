- 包含 0.2.12 的迷你播放器拖动进度 / 滚轮音量 / 睡眠定时，以及 0.2.11 的扫描并行读标签。

## English

Lekis Music 0.2.13 preview release, adding quick lyric-offset adjustments to the Now Playing "More" menu without opening the editor. Please [open an issue](https://github.com/aoxzh/lekis-music/issues) for problems.

**New**

- **Quick lyric offset**: the Now Playing "More" menu now offers "Lyrics 0.5s earlier / 0.5s later / Reset offset". The change refreshes lyrics immediately and writes back to the active lyric version, clamped to ±60 seconds.
- Includes the 0.2.12 mini-player seek / wheel volume / sleep timer, and the 0.2.11 parallel tag reads.

**Downloads:** Android arm64 APK; Windows x64 installer or portable ZIP; macOS arm64 DMG or ZIP; Linux x64 AppImage or tar.gz. Checksums are in `SHA256SUMS.txt`.
