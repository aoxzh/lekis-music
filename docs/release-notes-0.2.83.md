月兔音乐（Lekis Music）0.2.83 预览版，专辑和艺人页可以复制曲目列表。有问题欢迎[提 issue](https://github.com/aoxzh/lekis-music/issues)。

## 新增

- **专辑/艺人复制曲目列表**：专辑和艺人标题栏新增复制按钮，按「序号. 歌名 — 艺人」复制全部曲目。
- 包含 0.2.82 的用其他应用打开下载、0.2.81 的统计页最常听曲目播放和 0.2.80 的下载页缓存。

## English

Lekis Music 0.2.83 preview release, adding copy-track-list to album and artist pages. Please [open an issue](https://github.com/aoxzh/lekis-music/issues) for problems.

**New**

- **Copy an album's or artist's track list**: both headers gain a copy button that produces a numbered "Title — Artist" list.
- Includes the 0.2.82 open-download-with-app, 0.2.81 Top Tracks actions and 0.2.80 downloads cache.

**Downloads:** Android arm64 APK; Windows x64 installer or portable ZIP; macOS arm64 DMG or ZIP; Linux x64 AppImage or tar.gz. Checksums are in `SHA256SUMS.txt`.
