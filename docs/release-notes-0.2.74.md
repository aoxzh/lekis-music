月兔音乐（Lekis Music）0.2.74 预览版，设置里可以查看并清除图片缓存。有问题欢迎[提 issue](https://github.com/aoxzh/lekis-music/issues)。

## 新增

- **图片缓存管理**：设置 → 高级新增性能区，显示当前 Flutter 图片缓存占用/上限与张数，可一键清除；清空后立即刷新显示。
- 包含 0.2.73 的队列下载管理、0.2.72 的复制队列和 0.2.71 的正在播放查看专辑/艺人。

## English

Lekis Music 0.2.74 preview release, adding image-cache management in Settings. Please [open an issue](https://github.com/aoxzh/lekis-music/issues) for problems.

**New**

- **Image cache management**: Settings → Advanced now shows the current Flutter image-cache usage, limit, and image count, with a Clear button that refreshes the figure immediately.
- Includes the 0.2.73 queue download management, 0.2.72 copy queue and 0.2.71 Now Playing album/artist links.

**Downloads:** Android arm64 APK; Windows x64 installer or portable ZIP; macOS arm64 DMG or ZIP; Linux x64 AppImage or tar.gz. Checksums are in `SHA256SUMS.txt`.
