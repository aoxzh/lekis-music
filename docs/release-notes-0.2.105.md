月兔音乐（Lekis Music）0.2.105 预览版，长列表滚动更顺滑。有问题欢迎[提 issue](https://github.com/aoxzh/lekis-music/issues)。

## 性能

- **分页预取**：资料库长列表在接近页尾 / 页首时提前加载相邻页，快速滚动跨页不再闪现占位行。
- 包含 0.2.104 的打乱未播放曲目、0.2.103 的电台本地搜索和 0.2.102 的清除未播放曲目。

## English

Lekis Music 0.2.105 preview release, with smoother long-list scrolling. Please [open an issue](https://github.com/aoxzh/lekis-music/issues) for problems.

**Performance**

- **Page prefetching**: long library lists load the adjacent page as you approach a page edge, so fast scrolling across boundaries no longer flashes placeholder rows.
- Includes the 0.2.104 shuffle-upcoming queue action, 0.2.103 local radio search and 0.2.102 clear-upcoming action.

**Downloads:** Android arm64 APK; Windows x64 installer or portable ZIP; macOS arm64 DMG or ZIP; Linux x64 AppImage or tar.gz. Checksums are in `SHA256SUMS.txt`.
