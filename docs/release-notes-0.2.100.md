## English

Lekis Music 0.2.100 preview release, adding duplicate removal for playlists. Please [open an issue](https://github.com/aoxzh/lekis-music/issues) for problems.

**New**

- **Remove duplicate playlist tracks**: a playlist menu action removes repeated entries while keeping the first occurrence, with confirmation, progress, and a failed-count report.
- Includes the 0.2.99 search load-more, 0.2.98 search cache and 0.2.97 play-filtered-downloads.

**Downloads:** Android arm64 APK; Windows x64 installer or portable ZIP; macOS arm64 DMG or ZIP; Linux x64 AppImage or tar.gz. Checksums are in `SHA256SUMS.txt`.
