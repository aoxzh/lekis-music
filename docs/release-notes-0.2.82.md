月兔音乐（Lekis Music）0.2.82 预览版，下载文件可以用系统默认应用打开。有问题欢迎[提 issue](https://github.com/aoxzh/lekis-music/issues)。

## 新增

- **用其他应用打开下载**：下载行菜单新增桌面端「用其他应用打开」，可用系统默认播放器/程序打开缓存文件。
- 包含 0.2.81 的统计页最常听曲目播放、0.2.80 的下载页缓存和 0.2.79 的统计页跳转。

## English

Lekis Music 0.2.82 preview release, adding "open with default app" for downloads. Please [open an issue](https://github.com/aoxzh/lekis-music/issues) for problems.

**New**

- **Open a download with another app**: the download row sheet can launch the cached file in the system's default player or app on desktop.
- Includes the 0.2.81 Top Tracks actions, 0.2.80 downloads cache and 0.2.79 stats navigation.

**Downloads:** Android arm64 APK; Windows x64 installer or portable ZIP; macOS arm64 DMG or ZIP; Linux x64 AppImage or tar.gz. Checksums are in `SHA256SUMS.txt`.
