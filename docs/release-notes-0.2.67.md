月兔音乐（Lekis Music）0.2.67 预览版，歌单可以反转或随机重排。有问题欢迎[提 issue](https://github.com/aoxzh/lekis-music/issues)。

## 新增

- **歌单反转/随机顺序**：排序菜单新增「反转顺序 / 随机顺序」，同样保存到歌单并显示确认与进度；随机顺序每次都会重新打乱。
- 包含 0.2.66 的复制智能歌单、0.2.65 的歌单排序和 0.2.64 的下载进度节流。

## English

Lekis Music 0.2.67 preview release, adding reverse and shuffle order for playlists. Please [open an issue](https://github.com/aoxzh/lekis-music/issues) for problems.

**New**

- **Reverse / shuffle a playlist**: the sort sheet gains Reverse Order and Shuffle Order; both save the new order with the same confirmation and progress, and shuffle reshuffles every time.
- Includes the 0.2.66 smart-playlist duplication, 0.2.65 playlist sorting and 0.2.64 throttled download progress.

**Downloads:** Android arm64 APK; Windows x64 installer or portable ZIP; macOS arm64 DMG or ZIP; Linux x64 AppImage or tar.gz. Checksums are in `SHA256SUMS.txt`.
