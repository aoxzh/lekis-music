月兔音乐（Lekis Music）0.2.111 预览版，喜欢的歌曲可以整组下载。有问题欢迎[提 issue](https://github.com/aoxzh/lekis-music/issues)。

## 新增

- **喜欢的歌曲整组下载**：喜欢页新增「下载全部」，分页收集全部收藏并跳过已在本机的曲目，带确认和进度。
- 包含 0.2.110 的喜欢页随机播放、0.2.109 的电台本地排序和 0.2.108 的歌单随机播放。

## English

Lekis Music 0.2.111 preview release, adding batch download for Liked Songs. Please [open an issue](https://github.com/aoxzh/lekis-music/issues) for problems.

**New**

- **Download all Liked Songs**: the Liked Songs header can collect every favorite in pages, skip tracks already on this device, and queue them with confirmation and progress.
- Includes the 0.2.110 Liked Songs shuffle, 0.2.109 radio local sort and 0.2.108 playlist shuffle.

**Downloads:** Android arm64 APK; Windows x64 installer or portable ZIP; macOS arm64 DMG or ZIP; Linux x64 AppImage or tar.gz. Checksums are in `SHA256SUMS.txt`.
