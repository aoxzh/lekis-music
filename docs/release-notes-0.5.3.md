月兔音乐（Lekis Music）0.5.3 预览版：播放页默认更简洁，三个歌词浮层控件改为按需开启。有问题欢迎[提 issue](https://github.com/aoxzh/lekis-music/issues)。

## 改进

- 「曲目刻度」入口、歌词来源标识（如「在线歌词 · LRC」）和歌词偏移快捷条默认隐藏。
- 在「设置 → 歌词」新增三个开关，可分别开启：
  - 显示曲目刻度按钮
  - 显示歌词来源
  - 显示歌词偏移快捷条
- 歌词偏移仍可通过播放页「更多」菜单调整；隐藏这些浮层不影响歌词编辑和搜索。

## English

Lekis Music 0.5.3 preview release keeps the Now Playing screen clean by default. Please [open an issue](https://github.com/aoxzh/lekis-music/issues) for problems.

**Improvements**

- The track dial button, lyrics source badge (“Online · LRC”) and lyrics offset bar are hidden by default.
- Settings → Lyrics now has three switches to enable each one:
  - Show track dial button
  - Show lyrics source
  - Show lyrics offset bar
- Offset adjustments remain available in the Now Playing “More” menu; lyrics editing and search are unaffected.

**Downloads:** Android arm64 APK; Windows x64 installer or portable ZIP; macOS arm64 DMG or ZIP; Linux x64 AppImage or tar.gz. Checksums are in `SHA256SUMS.txt`.
