月兔音乐（Lekis Music）0.2.110 预览版，喜欢的歌曲可以一键随机播放。有问题欢迎[提 issue](https://github.com/aoxzh/lekis-music/issues)。

## 新增

- **喜欢的歌曲随机播放**：喜欢的歌曲页头部改为统一的播放 / 随机按钮组，可直接打乱全部收藏开播。
- 包含 0.2.109 的电台本地排序、0.2.108 的歌单随机播放和 0.2.107 的歌单合并。

## English

Lekis Music 0.2.110 preview release, adding shuffle play for Liked Songs. Please [open an issue](https://github.com/aoxzh/lekis-music/issues) for problems.

**New**

- **Shuffle Liked Songs**: the Liked Songs header now uses the shared Play / Shuffle pair, starting all favorites in random order.
- Includes the 0.2.109 radio local sort, 0.2.108 playlist shuffle and 0.2.107 playlist merge.

**Downloads:** Android arm64 APK; Windows x64 installer or portable ZIP; macOS arm64 DMG or ZIP; Linux x64 AppImage or tar.gz. Checksums are in `SHA256SUMS.txt`.
