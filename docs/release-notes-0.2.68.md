月兔音乐（Lekis Music）0.2.68 预览版，歌单很多歌时可以搜索过滤。有问题欢迎[提 issue](https://github.com/aoxzh/lekis-music/issues)。

## 新增

- **歌单搜索**：曲目较多时歌单详情出现搜索框，可按标题/艺人/专辑即时过滤；过滤时上下移动暂时禁用，点击结果只播放匹配曲目。
- 包含 0.2.67 的反转/随机顺序、0.2.66 的复制智能歌单和 0.2.65 的歌单排序。

## English

Lekis Music 0.2.68 preview release, adding search inside playlists. Please [open an issue](https://github.com/aoxzh/lekis-music/issues) for problems.

**New**

- **Playlist search**: large playlists show a search field and filter by title, artist, or album as you type. Reordering is disabled while filtering, and tapping a result plays only the matching tracks.
- Includes the 0.2.67 reverse/shuffle order, 0.2.66 smart-playlist duplication and 0.2.65 playlist sorting.

**Downloads:** Android arm64 APK; Windows x64 installer or portable ZIP; macOS arm64 DMG or ZIP; Linux x64 AppImage or tar.gz. Checksums are in `SHA256SUMS.txt`.
