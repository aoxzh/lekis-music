## 新增

- **艺人页显示全部歌曲**：歌曲超过 50 首时，标题右侧和列表底部都会出现「显示全部 N 首」，可展开完整列表并再收起；切换艺人会回到默认的 50 首预览。
- 包含 0.2.47 的艺人页下载全部歌曲、0.2.46 的下载列表刷新优化和 0.2.45 的重试全部失败下载。

## English

Lekis Music 0.2.48 preview release, adding expandable song lists on artist pages. Please [open an issue](https://github.com/aoxzh/lekis-music/issues) for problems.

**New**

- **Show all songs on artist pages**: when an artist has more than 50 songs, both the section header and the bottom of the list offer "Show all N songs"; the list can be collapsed again, and switching artists returns to the 50-song preview.
- Includes the 0.2.47 download-all-for-artist, 0.2.46 downloads refresh optimization and 0.2.45 retry-all-failed.

**Downloads:** Android arm64 APK; Windows x64 installer or portable ZIP; macOS arm64 DMG or ZIP; Linux x64 AppImage or tar.gz. Checksums are in `SHA256SUMS.txt`.
