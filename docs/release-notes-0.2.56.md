月兔音乐（Lekis Music）0.2.56 预览版，下载列表点整行即可播放。有问题欢迎[提 issue](https://github.com/aoxzh/lekis-music/issues)。

## 新增

- **下载列表点击播放**：已完成的下载整行可点，直接播放该曲目；下载中/失败行的按钮行为保持不变。
- 包含 0.2.55 的歌曲库一键播放、0.2.54 的 Windows 托盘当前歌曲和 0.2.53 的复制歌词。

## English

Lekis Music 0.2.56 preview release, making completed download rows play on tap. Please [open an issue](https://github.com/aoxzh/lekis-music/issues) for problems.

**New**

- **Tap a download to play**: a completed download's whole row now plays the track; active and failed rows keep their existing button behaviour.
- Includes the 0.2.55 library play-all, 0.2.54 Windows tray now-playing tooltip and 0.2.53 copy lyrics.

**Downloads:** Android arm64 APK; Windows x64 installer or portable ZIP; macOS arm64 DMG or ZIP; Linux x64 AppImage or tar.gz. Checksums are in `SHA256SUMS.txt`.
